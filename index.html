홈 화면에 앱 추가

  1. Safari 아래(또는 위)의 공유 버튼 ⬆︎ 을 누르세요.
  2. 목록에서 ‘홈 화면에 추가’를 선택하세요.
  3. 오른쪽 위 ‘추가’를 누르면 앱 아이콘이 생깁니다.

Chrome·카카오톡 등 다른 앱 안에서 열었다면 먼저 Safari로 열어 주세요.

⚠️ 사진이 AI 서버로 전송됩니다

‘AI 실제 합성’을 누르면 지금 화면의 사진이 선택한 AI 제공사(Google Gemini) 서버로 전송되어 처리됩니다. 라이브 모드와 일반 미리보기는 지금처럼 기기 안에서만 처리돼요.

  • 고객에게 사진 전송에 대해 동의를 받은 뒤 사용하세요.
  • 요청마다 제공사 요금이 부과될 수 있어요 (약 $0.07/장, 사장님 API 키 계정으로 청구).
  • 결과 이미지는 AI가 새로 그린 것이라 실제 시술 결과와 다를 수 있어요.

⚙️ AI 실제 합성 설정

🔒 키는 이 기기의 브라우저(localStorage)에만 저장되고, 선택한 AI 제공사로만 전송돼요. 공용 기기에서는 사용 후 키를 지워 주세요.
